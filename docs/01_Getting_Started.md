# 🚀 Getting Started

Welcome to the **Digital Design & ASIC Design Portfolio**.

This repository is a collection of digital design projects, documentation, and tutorials created while learning modern ASIC design using open-source EDA tools.

Whether you are a student beginning with Verilog or someone interested in understanding the complete RTL-to-GDSII flow, this repository aims to provide practical examples and hands-on guidance.

---

# 🎯 Objectives

The goals of this repository are to:

- Learn Digital Design from fundamentals
- Build reusable Verilog projects
- Practice functional verification
- Learn Logic Synthesis using Yosys
- Perform Static Timing Analysis (STA) using OpenSTA
- Explore ASIC Physical Design using OpenROAD
- Generate and visualize GDSII layouts
- Document the complete learning journey

---

This repository is intended for:

# 💡 How to Use This Repository

If you're new to Digital Design:

1. Read the documentation in the `docs` folder.
2. Study the theory behind each topic.
3. Explore the corresponding project.
4. Simulate the RTL.
5. Analyze the waveform.
6. Perform synthesis.
7. Check timing using OpenSTA.
8. Complete the physical design flow using OpenROAD.
9. Visualize the final GDSII using KLayout.

Following this sequence will help you understand how a digital circuit progresses from an idea to a manufacturable chip layout.
