# Arithmetic Logic Unit (ALU)

## Purpose

The Arithmetic Logic Unit (ALU) performs arithmetic and logical operations on operands read from the Register File.

The operation performed is selected using a 4-bit opcode generated by the Control Unit.

---

## Parameters

| Parameter | Description | Default |
|-----------|-------------|---------|
| DATA_WIDTH | Width of each operand | 8 |

---

## Inputs

| Signal | Width | Description |
|---------|------:|-------------|
| A | 8 | Operand A |
| B | 8 | Operand B |
| opcode | 4 | ALU Operation Select |

---

## Outputs

| Signal | Width | Description |
|---------|------:|-------------|
| Result | 8 | Operation Result |
| Zero | 1 | Asserted when Result equals zero |

---

## Supported Operations

| Opcode | Operation | Description |
|---------|-----------|-------------|
| 0000 | ADD | Addition |
| 0001 | SUB | Subtraction |
| 0010 | AND | Bitwise AND |
| 0011 | OR | Bitwise OR |
| 0100 | XOR | Bitwise XOR |
| 0101 | NOT | Bitwise NOT of A |
| 0110 | SHL | Shift A Left by 1 |
| 0111 | SHR | Shift A Right by 1 |
| 1000 | PASS A | Pass Operand A |
| 1001 | PASS B | Pass Operand B |

---

## Operation

The ALU is purely combinational.

Whenever an input operand or opcode changes, the output updates immediately.

No clock or reset is required.

---

## Zero Flag

The Zero flag is asserted whenever the ALU result equals zero.

Example:

```
A = 5
B = 5
Operation = SUB

Result = 0
Zero = 1
```
