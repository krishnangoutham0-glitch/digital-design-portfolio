# Digital Design Portfolio

> A collection of digital hardware design projects implemented in Verilog HDL and verified through simulation, functional coverage, synthesis, and gate-level simulation.

---

## About

This repository documents my journey in Digital Design and ASIC Front-End Design.

Each project follows a complete RTL design flow:

- RTL Design (Verilog HDL)
- Testbench Development
- Functional Simulation (Icarus Verilog)
- Coverage Analysis (Verilator)
- Logic Synthesis (Yosys)
- Gate-Level Simulation
- Documentation

The goal of this repository is to demonstrate practical RTL design skills and build a strong portfolio for Digital/ASIC/VLSI roles.
