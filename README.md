# 🛠 ASIC Design Flow

Every project follows as much of the complete ASIC flow as possible.

```
Specification
      │
      ▼
RTL Design (Verilog)
      │
      ▼
Functional Simulation
      │
      ▼
Logic Synthesis (Yosys)
      │
      ▼
Static Timing Analysis (OpenSTA)
      │
      ▼
Floorplanning
      │
      ▼
Placement
      │
      ▼
Clock Tree Synthesis
      │
      ▼
Routing
      │
      ▼
Parasitic Extraction
      │
      ▼
Final Timing Analysis
      │
      ▼
GDSII Generation
```
